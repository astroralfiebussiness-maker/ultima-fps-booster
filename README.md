# Ultima FPS Booster

A high-performance Fabric mod for Minecraft that significantly boosts FPS through advanced optimization techniques.

## Features

✨ **Advanced Rendering Optimizations**
- Improved frustum culling for better entity and chunk rendering
- Reduced draw calls through intelligent batching
- Optimized particle rendering with smart limiting
- Enhanced block entity culling

⚡ **Performance Enhancements**
- Far-distance entity rendering optimization
- Chunk loading pipeline improvements
- Memory-efficient rendering pipeline
- Reduced unnecessary rendering passes

🎮 **Game Renderer Improvements**
- Optimized game renderer pipeline
- Better shadow rendering optimization
- Improved lighting calculations
- Reduced overhead in entity shadows

## Installation

1. Download the latest release JAR file
2. Place it in your `.minecraft/mods` folder
3. Ensure Fabric Loader and Fabric API are installed
4. Launch Minecraft with the Fabric profile

## Compatibility

- **Minecraft Version**: 1.20.1
- **Loader**: Fabric Loader 0.14.25+
- **Fabric API**: Required

## Configuration

The mod includes configurable options for:
- Advanced culling toggles
- Particle reduction levels
- Chunk loading optimization
- Entity shadow rendering
- Lighting optimization

## Performance Impact

Expect:
- 20-40% FPS increase on average systems
- 40-60% FPS increase with all optimizations enabled
- Reduced GPU load and memory usage
- Smoother gameplay experience

## Building from Source

```bash
git clone https://github.com/astroralfiebussiness-maker/ultima-fps-booster.git
cd ultima-fps-booster
./gradlew build
```

The compiled mod will be in `build/libs/`
